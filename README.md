# Hotel-Canellation-Analysis
A data analysis project using Python, EDA, and business recommendations focused on understanding hotel booking behavior, cancellation patterns, booking channels, room type performance, and business recommendations.

## Project Objective
The goal of this project is to analyze hotel booking data and identify:
- booking trends
- cancellation behavior
- revenue patterns
- performance across channels, room types, and star ratings
- actionable business recommendations

## Files in this Repository
- `Hotel_Analysis(Piyush_Kumar_Jha).ipynb` — Jupyter notebook with analysis
- `Hotel_bookings_final.csv` — dataset used for analysis
- `Hotel Bookings Analysis.pdf` — final report
- `images/` — charts and visualizations used in README/report

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Web bookings showed the strongest quality with the lowest cancellation rate and highest average booking value.
- Standard rooms contributed the highest booking volume but also had the highest cancellation risk.
- Deluxe rooms offered a better balance between scale and stability.
- Star rating did not show a major difference in cancellation behavior, suggesting channel and room type matter more.
- Booking value increased over time, while average stay length remained mostly stable.

## Business Recommendations
- Tighten cancellation rules for high-risk segments such as travel agent and standard room bookings
- Push more traffic toward direct web bookings
- Improve app and payment flow performance
- Use pricing and cancellation policy together during peak periods
- Build loyalty or repeat-booking incentives
